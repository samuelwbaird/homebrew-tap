# homebrew-tap

Homebrew formulae for [rascal](https://github.com/samuelwbaird/rascal).

```bash
brew install samuelwbaird/tap/rascal
```

`Formula/rascal.rb` is updated automatically by rascal's release workflow, from each release's prebuilt executables (macOS arm64 and x86_64, Linux x86_64 and aarch64).
